# idea-research

点子落地调研 Skill：澄清点子 → 调查已有方案与实现进展 → 给出有证据的落地建议。

当前版本：**v0.1.0，预发布**。当前仓库保持私有，尚未选择对外开源许可；不将此版本视为稳定性承诺。

## 做什么

- 面向软件、网站、小工具、自动化与浏览器插件的开发前决策。
- 信息不足时少量追问，完整简报直接进入调研。
- GitHub 优先，官网和商店补漏，社区辅助核验；浏览器扩展固定覆盖。
- 区分正式发布、源码可见与计划，也区分读文档、查源码与实际试用。
- 给出直接使用、组合改造、自建差异部分或调整方向的建议，以及下一步验证。
- 中文固定十章报告，目的是减少重复制作，不是自动开始开发。

核心是一个自包含文件：[SKILL.md](.agents/skills/idea-research/SKILL.md)。没有额外脚本、运行时依赖、网站或服务；不依赖 grill-me、deep-research 或其他研究 Skill，完全排除 learn。

## 项目内使用

在此仓库根目录的 Codex 任务中调用：

```text
$idea-research 我想研究一个自用网页摘录工具：Windows、Edge，手动保存选中文字、来源 URL 和摘录时间，输出到本地 Markdown，不要求账号、同步或移动端。优先评估已有扩展和组件，只在明确缺口存在时考虑补充实现。请调研现有方案，不安装任何软件、不开始编码。
```

在已经进入仓库根目录的 PowerShell 中也可使用：

```powershell
codex exec '$idea-research 我想做一个网页资料整理工具，请先帮我澄清，再调研已有方案。'
```

单引号可避免 PowerShell 展开 `$idea-research`。本仓库采用项目级 `.agents/skills/idea-research/` 路径，不需要全局安装。项目上下文 CLI 发现和调用已测试，桌面菜单显示、父目录热加载和自动触发尚未验证。

使用宿主已经提供的公开检索与读取能力，不自动配置账号、Key、服务或插件。报告服从用户指定路径；未指定时保存在当前项目的 `runs/<日期时间>-<主题>/report.md`，冲突时新建目录。运行报告被 Git 忽略，不会随常规提交上传。

## 边界与验证

不适用于单个视频/链接总结或直接修改代码；不安装、运行被调研项目，不自动注册、付费、上传、改配置或开发产品。没有网络时明确标记“未开展外部调研”；未实际试用不能声称实测。

参见 [验证摘要](VALIDATION.md) 和 [可复用测试用例](tests/idea-research-cases.md)。已进行真实联网调用并产出报告，但**并非全部验收通过**：商店实时详情受限，原始执行曾暴露安全/编码/引用问题；已做窄修正，最终引用规则修订后未再完整联网重跑。
